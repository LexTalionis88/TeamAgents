# Выбор бесплатных моделей OpenRouter для agent workflow

## Решение

Для экспериментов с автономным .NET workflow зафиксирован следующий порядок
моделей OpenRouter:

1. `google/gemma-4-26b-a4b-it:free` — основной кандидат.
2. `dots-studio/dots-3-note-preview:free` — резервный кандидат.

Модель указывается явно через `OPENROUTER_MODEL`. Маршрутизатор
`openrouter/free` не используется в сравнительных прогонах, потому что он
может выбирать разные бесплатные модели для последовательных вызовов одного
workflow.

## Причины выбора

- Gemma 4 26B A4B заявляет поддержку function calling и JSON-ответов и имеет
  большой контекст. Она проверяется первой как наиболее сбалансированный
  кандидат для typed-контрактов и MCP tools.
- Dots3-Note Preview ориентирована на coding и многошаговые agent workflow,
  поддерживает tools и structured outputs. Она используется как fallback,
  если Gemma недоступна или нестабильна.

Это порядок проверки, а не изменение провайдера по умолчанию и не предметная
логика workflow. Каждый кандидат должен пройти одинаковую проверку:

- валидные typed JSON-ответы Manager и Architect;
- фактические MCP tool calls от Developer;
- применение workspace patch;
- прохождение Tester, Security и Reviewer;
- отсутствие изменений в AgentClient, McpServer и общем workflow при решении
  предметной задачи.

## Ограничения

Бесплатные endpoint могут иметь отдельные лимиты, задержки, ошибки провайдера
и временную доступность. Поэтому итоговый выбор подтверждается только
полноценным E2E-прогоном на реальной задаче, а не одним успешным ответом.
