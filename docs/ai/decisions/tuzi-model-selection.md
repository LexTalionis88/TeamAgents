# Выбор модели Tuzi для agent workflow

## Результат проверки

На 23 сентября 2026 года каталог Tuzi возвращает несколько моделей с суффиксом
`-free`, но chat-запросы к ним отклоняются ошибкой `model_price_error`. Это
означает, что бесплатный тариф для текущего маршрутизатора или аккаунта не
настроен. Модель `step-3.7-flash-free` вместо этого возвращает HTTP 400.

Следовательно, среди фактически доступных бесплатных моделей нельзя выбрать
рабочую модель для agent workflow.

## Сравнение доступных кандидатов

| Модель | Короткий chat | Tool call | Полный workflow |
|---|---:|---:|---|
| `gpt-5.4` | да | да | остановлен из-за недостаточной квоты |
| `gemini-2.5-flash-lite` | да | да | вызвал MCP tools, затем получил `content_filter` на длинном контексте |
| `gpt-4.1-mini` | да | да в прямом probe | Developer завершил без фактического MCP patch |
| `gpt-4.1-nano` | да | да в прямом probe | полный workflow не запускался |
| `gpt-4o-mini` | да | частично | Developer не выполнил MCP patch |

## Решение

Для текущего `TuziChatClientProvider` используется недорогой default
`gpt-4.1-mini`, а модель можно явно переопределить через `TUZI_MODEL`.
`gemini-2.5-flash-lite` остаётся кандидатом для дальнейшего прогона после
сокращения контекста и проверки причины `content_filter`.

Секрет `TUZI_API_KEY` не должен попадать в исходники, документацию, prompt или
логи. Для каждого кандидата нужно подтверждать не только текстовый ответ, но и
фактические MCP `execute_tool`, patch и evidence.
