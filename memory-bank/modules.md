# Модули и функциональность

Текущие технические модули:

- `src/McpServer` — MCP-сервер и инструменты workspace.
- `src/AgentClient` — агент Microsoft Agent Framework, использующий локальный
  Ollama и инструменты MCP.

Предметные модули пока не определены. Описывай здесь назначение и границы новых
модулей по мере их появления.
